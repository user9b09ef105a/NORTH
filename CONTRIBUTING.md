# Contributing

Contributions are welcome.

1. Start from the latest `main`.
2. Keep the change focused.
3. Run the project checks.
4. Open a pull request.
5. Address review or Quality-check feedback if needed.

```powershell
.\scripts\test-powershell.ps1
.\scripts\check.ps1
```

Please only submit material you have the right to publish, and do not include credentials, private data, confidential information, or unlicensed media.

Accepted contributions are distributed under the repository's Apache License 2.0 unless a compatible third-party component is clearly identified with its own terms.
